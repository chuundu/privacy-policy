Privacy Policy

Effective Date: May 4, 2026

This personal automation tool accesses Google Calendar and Gmail data solely to provide calendar digests, schedule reminders, and inbox triage for Choolwe Nalubamba (“the user”).

Data Collected

  • Calendar events (read/write)
  • Gmail message metadata and bodies (read/modify/send)
  • User profile (openid, userinfo.email)

How Data Is Used

  • Generate daily/weekly incident and calendar digests
  • Send notifications and reminders
  • Assist with inbox triage (mark read, label, respond)
  • Create or update calendar events on behalf of the user

Data Storage

No calendar or email content is stored permanently. Data is processed in-memory on a secured private server and discarded after each task.

Data Sharing

Data is never shared with third parties. Access tokens and refresh tokens are stored securely on the user’s private server and are not distributed elsewhere.

User Control

  • Revoke access anytime: Google Account → Security → Third-party apps.
